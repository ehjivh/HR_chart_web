# 教育・研究用 WebベースHR図学習システム (Gaia DR3 HR-Diagram Workbench)

宇宙望遠鏡 **Gaia DR3** の実観測データをもとに、恒星の物理量を算出し、**ヘルツシュプルング・ラッセル図（HR図）** 上にプロットする過程を通じて、恒星の構造や進化を体系的に学ぶためのWebアプリケーションです。

単なるデータの可視化にとどまらず、**「① 何を観測し → ② 何を算出し → ③ HR図から何が分かるのか」** という天文学の科学的探究プロセスをWebブラウザ単体で完結できます。

---

## 主な特徴

### 1. 3段階の天文学習フレームワーク
1画面ダッシュボード上で、以下の3つのステップを切り替えながらHR図と連動して学習を進められます。

* **STEP ① 何を観測するのか（観測データの取得）**
  * **視等級 ($m_G$)**: 地球から観測した星の見かけの明るさ。
  * **年周視差 ($\varpi$ [mas])**: 地球の公転軌道を底辺とした視差角（ミリ秒角）。距離決定の基礎データ。
  * **色指数 ($G_{BP} - G_{RP}$ / $B - V$)**: 異なる波長フィルターを通した等級の差。
  * **Gaia Archive (TAP API) リアルタイム取得**: プリセット選択またはADQLクエリの直接編集により、IVOA TAPサーバーからリアルタイムにGaia DR3データを取得します（オフライン環境でも即座に動作する実観測データスナップショットを内蔵）。
  * **距離補正の視覚実験**: 縦軸を「視等級 $m_G$（距離補正前）」と「絶対等級 $M_G$（距離補正後）」でアニメーション切り替えし、なぜ年周視差による距離補正が必要なのかを視覚的に確認できます。

* **STEP ② 何を算出するのか（物理量への変換）**
  * **距離 ($d$) と 絶対等級 ($M$) の算出**: すべての恒星を共通基準である $10\text{ pc}$（約 $32.6\text{ 光年}$）に置いたときの本来の明るさを算出します。
    $$d\text{ [pc]} = \frac{1000}{\varpi\text{ [mas]}}, \qquad M = m + 5 + 5 \log_{10}\!\left(\frac{\varpi}{1000}\right)$$
  * **有効温度 ($T_{\text{eff}}$) の導出**: 色指数と黒体輻射（プランク分布）の温度補正モデルから表面温度 $\text{[K]}$ を導出します。
  * **物理量算出シミュレータ＆検算ミニ演習**: HR図上でクリックした恒星の観測値が数式へリアルタイムに代入・展開されるほか、学習者自身が手計算で絶対等級 $M$ を求めて正誤判定できる演習機能を備えています。

* **STEP ③ どうなるのか（HR図からの物理的解釈）**
  * **星の種類の識別**: HR図上の位置から **主系列星 (Main Sequence)**、**赤色巨星 (Red Giants)**、**超巨星 (Supergiants)**、**白色矮星 (White Dwarfs)** を分類・解説します。
  * **質量・半径・寿命の推定**: 質量-光度関係（$L \propto M_*^{3.5\sim 4}$）やシュテファン＝ボルツマン則（$L = 4\pi R^2 \sigma T_{\text{eff}}^4$）に基づき、恒星質量 $M_*/M_\odot$、水素核融合の主系列寿命 $\tau_{\text{MS}}$、および恒星半径 $R/R_\odot$ を推定します。
  * **等年齢線（Isochrone）フィッティング**: 理論等年齢線（$\log_{10}(\text{Age/yr}) = 7.10 \sim 10.05$）をスライダーで連続的に動かし、星団の主系列離脱点（MSTO: Turnoff Point）に重ね合わせることで星団の年齢（約1,200万年〜110億年）を読み解きます。

---

### 2. デザインポリシー（白黒モノトーン基調＋物理的色彩の限定使用）
* **モノトーン基調（白黒ベース）**: 学術論文の図表に準拠し、UIの枠線・背景・グリッド・軸・ボタン・テキストはすべて白・黒・ニュートラルグレーのみで構成しています。
* **物理的色彩の限定使用**: 散布図上の**恒星プロット**および**等年齢線カーブ**に限り、恒星の表面温度（有効温度 $T_{\text{eff}}$）に応じた黒体輻射の色温度を表現する目的でカラー表現を使用しています。
  * **高温の星（O・B・A型）**: 青〜青白色
  * **中温の星（F・G・K型、太陽周辺）**: 白〜黄色
  * **低温の星（M型赤色矮星・赤色巨星）**: オレンジ〜赤色

## 動作環境・起動方法

特殊なプラグインやバックエンドサーバーの構築は不要です。一般的なモダンWebブラウザ（Google Chrome, Microsoft Edge, Firefox, Safari）のみで動作します。

### 1. 直接ブラウザで開く場合
プロジェクトフォルダ内の `index.html` をダブルクリック（またはブラウザへドラッグ＆ドロップ）して開いてください。

### 2. ローカルHTTPサーバーで開く場合（任意）
Python や Node.js 等で簡易サーバーを起動してアクセスすることも可能です。

```powershell
# Python を使用する場合
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## CSVファイルの読み込み・書き出し

ヘッダー右上の **「CSV出力」「CSV読込」** ボタンから、手元の観測データを読み込んだり、算出した物理量（距離・絶対等級・有効温度・光度・半径・質量・分類）を含むテーブルをCSV形式で保存できます。

### 読み込み可能なCSVカラム名（カンマ区切り または タブ区切り）
* **視等級**: `phot_g_mean_mag`, `gmag`, `m_g`, `m`, `mag`, `v` のいずれか
* **年周視差 [mas]**: `parallax`, `plx` のいずれか（正の値）
* **色指数**: `bp_rp`, `bp-rp`, `b-v`, `b_v`, `color` のいずれか
* **天体ID（任意）**: `source_id`, `source`, `id`, `name`

## 使用技術・ライブラリ

* **データ・計算層**: Vanilla JavaScript (ES6+) / IVOA TAP (Table Access Protocol) ADQL Client
* **描画・可視化層**: HTML5 Canvas API + [D3.js v7](https://d3js.org/)
* **学習補助UI・数式描画**: [Tailwind CSS](https://tailwindcss.com/) (Monotone Theme) + [KaTeX](https://katex.org/)
